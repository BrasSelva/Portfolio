Pictur'Art

Une application web pour sauvegarder ses photos et les partager entre amis, dans des albums privés. Vos souvenirs restent entre de bonnes mains : les vôtres.

Fonctionnalités

  • Inscription et connexion à un compte personnel.
  • Création d'albums privés pour regrouper ses photos.
  • Recherche et filtres sur les albums : par date, par créateur et par nom d'album.
  • Navigation simple entre ses albums et son profil.

Architecture

Une application JavaScript de bout en bout : une interface en React, une API REST en Node.js / Express, et une base MongoDB pour les utilisateurs, les albums et les photos.
